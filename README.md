# 古籍解谜·中医传承

一个基于 Python + Pygame 开发的中医古籍解谜文字游戏，支持 Windows 桌面运行和浏览器在线游玩。

## 在线游玩

打开 [GitHub Pages 在线版](https://demetriusww.github.io/tcm-ancient-book-puzzle/) 即可直接游玩，无需安装 Python。网页版使用 Pygbag 将 Pygame 编译为 WebAssembly，游戏进度保存在当前浏览器的 localStorage 中。

每次推送到 `main` 分支后，GitHub Actions 会自动构建 WebAssembly 版本并发布到 GitHub Pages。

## 项目简介

玩家将扮演一位古籍修复者，通过收集残页线索、推理药材配伍，逐步修复五大中医古籍章节：解表、清热、补益、理气活血、祛湿化痰。每完成一个方剂谜题，即可解锁完整古籍页面、配伍解析与名医故事。

## 功能特点

- **五大古籍章节**：线性解锁机制，每章包含引言、3-5 个方剂谜题和篇末故事
- **四层推理逻辑**：残缺线索 → 药材筛选 → 君臣佐使配伍 → 方剂校验
- **四种谜题类型**：药性推理、病症反推、配伍补全、文字缺失补全
- **图鉴归档系统**：解谜成功后自动解锁方剂原文，可在“配伍方解 / 名医医案”页签间切换，并支持分页与随机回看
- **错题复盘系统**：把错误选择收进药签目录，可切换“错因提示 / 重看线索”，支持随机温故和直接再练
- **本地存档系统**：章节解锁状态、已修复数量、正确率统计、错题记录持久化
- **游戏设置**：可拖动文字速度与音量滑杆，实时预览打字节奏，并提供音乐开关与游戏重置
- **中医药主题场景**：百草柜、药罐、药材枝叶、宣纸纹理与水墨远山
- **本草互动札记**：点击百草柜查阅药材性味、归经与功效，解谜时悬停药材即可查看释义
- **动态卷面**：开篇与结局正文逐行浮现，线索封签可逐条拆开，导航、印章和药叶粒子会随操作产生反馈
- **今日药签**：主菜单每日推荐一味药材，每页底部提供鼓励语，并可点击“换一签”轮换
- **即时操作反馈**：选药药叶粒子、答题青玉/朱砂边框反馈与章节药草徽记

## 运行方式

### 方式一：使用 run.bat（推荐）

双击 `run.bat` 即可启动游戏。

### 方式二：命令行启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动游戏
python main.py
```

## 操作说明

- **鼠标左键**：点击按钮、拆封线索、选择药材、切换页签与输入文字
- **全局回退**：任意游戏页面点击左上角“回退”，或用 `Esc` 返回上一级
- **全局退出**：点击左上角“退出”，确认后关闭游戏；当前进度会自动保存
- **药材悬停**：查看当前药材的性味、归经与功效提示
- **主菜单今日药材**：点击“今日一味”卡或“点开本草札记”，查看当日药材资料
- **百草柜点击**：点击左右药柜抽屉，随时翻阅本草札记
- **线索拆封**：点击谜题上方的单张封签逐条查看线索，或点击“展卷”一次全部展开；已拆封线索可再次点击阅读完整内容
- **正文补全**：开篇、章节引言与结局正文正在浮现时，点击卷面可立即显示全文
- **底部药签**：点击页面最下方的“换一签”，轮换当前页的鼓励语
- **图鉴浏览**：点击方剂药签，“配伍方解 / 名医医案”切换内容；使用“上一页 / 下一页”、鼠标滚轮或“随机回看”翻阅
- **错题复盘**：切换“错因提示 / 重看线索”，使用“抽一题温故”或“再练一次”重新挑战
- **设置调节**：在文字速度与音量滑杆上按住鼠标拖动，松开即完成调节
- **键盘**：文字缺失补全类谜题可直接输入汉字

## 自定义内容

- 修改 `data/game_data.json` 可添加新章节、新谜题、调整剧情文本
- 将音乐文件放入 `assets/music/` 目录，游戏会自动播放
- 将中文字体文件放入 `assets/fonts/` 目录，可提升显示效果

## 注意事项

1. 本游戏完全离线运行，不产生任何网络请求
2. 存档文件位于 `save/save_data.json`，请勿随意删除
3. 文字缺失补全类谜题需按顺序补全空缺文字，再选择正确药材
4. 药材选择以集合方式校验，顺序不影响结果

## 开发说明

代码采用模块化设计，注释清晰，适合大学生学习参考：

- `puzzle_system.py`：核心解谜逻辑与方剂校验
- `save_manager.py`：JSON 本地存档读写
- `main.py`：游戏主循环与各状态界面绘制
